Security research, across the stack#

I’m Ectario, a blockchain security researcher working across smart contracts, virtual machines, validator clients, and applied cryptography. My interests span EVM and SVM security, DeFi, bridges, consensus, execution layers, nodes, and RPC infrastructure.

My work? Manual code review, exploit development, fuzzing, and invariant testing to understand where a system’s assumptions can fail. I also build open-source tools to make that work easier to inspect and reproduce.

Currently, i’m also developing multi-agent AI workflows for security research and finding triage.
